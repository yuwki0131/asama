# ビジュアルパトロール問題台帳

ランダムパトロール(`apps/game/qa/visual-patrol.mjs`)のスクリーンショットを
別コンテキストVLMレビュアーに並列投入して抽出した違和感を、クラスタ単位で
管理する台帳。サイクル: 撮影 → 抽出 → 台帳整理 → 実装方針 → 修正 →
同seed再撮影で収束確認 → 理解できた問題はルール化(art-rulebook.md / artLint /
composite-lint)して機械検査へ昇格。

- ステータス: `open` / `fixing` / `fixed(検証待ち)` / `closed(ルール化済み)` / `deferred`
- 優先度: ユーザー直接指摘は無条件P0。それ以外は 頻度×深刻度。

## サイクル1 — 2026-08-21, seed 20260811, ogaki-castle 13ビュー

レビュアー4バッチ(各3〜4ビュー、5カテゴリ+自由記述)。撮影物:
`artifacts/visual-patrol/ogaki-castle/2026-08-21T12-37-04/`

### V-01 水面の64pxタイル格子反復(川・水堀) — P0 / closed(ルール化済み)

- 出現: first, p04, p06, p09, p10, p11, p12(全ズームで即認識。「壁紙」評)
- 症状: 川・堀の水面が菱形ウロコ/シェブロン紋の完全反復。
- 根因(確定):
  - 見えている紋様はアセット内の絵ではなく**64pxタイル格子そのもの**。
    川/堀のbuilding内部水面タイル(`building-river-connected-1111`等)は
    単一スプライトの反復で、AAされたタイル菱形輪郭+タイル内で同一の微小
    ノイズが格子周期で並び、鱗状に読める。
  - 直線部(0101/1010)の位相バリアントp1-p3は存在するが絵がほぼ同一
    (raw/final共にmeanAbsDiff≈13/765)。水マテリアルの明暗レンジが極小
    (dark(0.022,0.052,0.075)↔light(0.045,0.088,0.115))で位相が読めない。
  - 地形waterは同問題をmacro場(連続ノイズを4x4スライス、
    `terrain.water.macro.v{n}.{x%4}.{y%4}`)で解決済みだが、川/堀
    (building)には未適用。
- 実施した修正(macro場は不要だった — 根因は影とコントラストの2点):
  1. **Holdoutスカートの影除去**: Cyclesでは Holdout 面も影を落とす。地表高
     (z=0.0005)のスカートが沈んだ床(-0.22)の北隅に全タイル同一の暗帯
     (luma40 vs 本体63)を落とし、これが格子周期で鱗状に読めていた。分離
     レジストリ `render_asset_lib/trench/`(entry: render_trench_asset.py)で
     `disable_holdout_shadows`(visible_shadow=False)を適用。
  2. **バリアント実効コントラスト拡大**: 水面ランプの明側引き上げ+急峻化、
     空堀床ランプ拡幅、bank(土手)材の土壌ランプ拡幅(空堀は画素の大半が
     土手のため床だけでは不足)。位相p1-p3/シードv1の実測meanAbsDiffは
     8-13 → 14.2-31.5(全60ペアが閾値12超)。
  3. **ルール化(VAR-01)**: artLintに「バリアントプールの実効画素差分≥12」
     検査を追加(checks.ts checkVariantDiff + テスト)。レガシーのサブ可視
     ペア47件はbaseline棚卸し。rulebookにVARセクション。
- 検証: 同一seed(20260811)再パトロール、別コンテキストVLMの前後比較で
  first/p04/p06/p10全て「解消・新規違和感なし」(2026-08-22T10-19-18 run)。
  composite-lint error 0。分離レジストリのため他510アセットのキャッシュ不変。

### V-02 マップ端の描写 — P0(ユーザー直接指摘) / closed(ルール化済み)

- 出現: p01(画面1/4が漆黒), p09右上, p10右上, p11右下
- 症状: マップ外周が無処理の黒ボイドへカミソリ状の斜め直線で切れ落ちる。
  ユーザー指摘:「端を横切るようにして、別の端が表示されている箇所がある」
  (端をまたいだ先に別の端の描写が見える)。
- 根因(確定、2点複合。当初仮説のcliffInfoForは本マップでは無関係):
  1. **偽の縁取り(「別の端」の正体)**: `connectedTerrainAssetId`
     (simulation/map.ts)がマップ外隣接を異種地形("0")扱いし、リム全周の
     セルに内部の地域境界と同一の汀・フリンジ縁アートを描かせていた。
     境界線がリムに沿って走り「端の先にもう一つの端」に読める。
  2. **外周処理の不在**: リムの先は背景色(0x1c2227)へのカミソリカット。
  - cliffInfoForのマップ外高さ0フォールバック仮説は実測で棄却: 大垣城の
    外周508セルは全て標高0(grass503/water5)で幻の崖面は発生しない。
    ただし**外周に高台が接する将来マップでは潜在問題として残る**(要注意)。
- 実施した修正:
  1. **sim**: `connectedTerrainAssetId`のマップ外隣接を同種("1")扱いに変更
     — リムでは世界が外へ続いているとして描く(汀・フリンジ縁を出さない)。
  2. **renderer**: 外周スカート(terrainLayer)。リム地形を12リング分外へ
     続けるpseudo-cell群(`buildPerimeterSkirtCells`、grass/dirt/waterは
     macro場のハッシュ式で外挿し反復を避ける)+背景色キャンバスグラデーション
     のフェードオーバーレイ(`buildSkirtFadeOverlay`、辺4バンド+コーナー4
     ラジアル)。リングごとのper-cellアルファ段付けは縞に見えたため不採用、
    Pixi FillGradientはlinear斜め方向のclamp座標スワップとradialの不透明
    ベース塗りの2バグで不採用 — 自前キャンバステクスチャ+シアーSprite。
  3. **ルール化(EDGE-01)**: composite-lintにEDGEチェック追加。地形レイヤ
     表示/非表示の2枚差分でスカート寄与の到達距離をレイ計測し、中央値
     ≥120px×zoomを要求(単一背景色比較はヘイズ勾配を誤読するため不可)。
     専用エッジビュー6点(edgeViews)を composite-views.json に登録。
     rulebookにEDGEセクション。負検証(スカート無効化)で3/3ビューerror検出
     を確認。
- 検証: 端狙い撃ち5ビュー(西/南/北の辺、NW/SE角、川の端流出部)で溶暗を
  目視確認、composite-lint 全12ビュー error 0。同seed再パトロール実施済み
  (下記サイクル2)。

### V-03 高低差エッジの違和感 — P0(ユーザー直接指摘) / closed(ルール化済み)

- 出現: ユーザー指摘(典型的違和感)。パトロールではp05左上の白灰パッチ

  1. 【高】崖天端に濃グレーの平帯が一周し草地を「額縁」状に縁取り、草側も
     直線の硬いエッジ(はみ出し・馴染みなし)→ 段丘が箱状の台に見える

- 実施した修正(elevation分離レジストリ、54アセットのみ再レンダー・他573不変):
  1. **額縁化(症状1)**: 石垣天端に連続ソッドリップ(`SodLip` _face_box)+

     帯の正体はピクセル帰属で `terrain-ishigaki-face-*` 天端アート自体と確定
     (塀建物ではない)。
  2. **同化(症状2)**: KiriStoneパレットの明側引上げ+暖色化(5材とも)。
     石垣面が明・暖側に分離し、上載の塀は暗いスレート調のまま残るため
     明度階層で高低差が読める。
  3. **接地感(症状3、陸側)**: 足元の苔帯を主帯+ラグドクランプ6個に増強。
     水際(堀に落ちる面)は今回の変更対象外(bank/rim系)のためV-06に統合。
  4. **コーナー縦シーム(症状4)**: E面材の1.30ブースト(法線陰面の補償)。
     実測lumaはs=66.6/e=68.1でほぼ揃った。
  5. **屋根見え(症状5)**: StepStoneDark明度引上げ(0.128→0.160系)+
     暗スラブ出現率減(roll>0.65→0.82)。
- ルール化: 合成起因のためL1昇格不可 — art-rulebookに**ELEVセクション**
  (ELEV-01〜05のL2レビューカード)を新設。検証手段は狙い撃ちビュー+
  別コンテキストVLMと明記。
- 検証: 同6ビュー再撮影(2026-08-22T13-49-18)、別コンテキストVLM前後比較で
  症状1/2/4/5改善・3は陸側改善(水際はV-06へ)・新規違和感なし、総合合格。
  composite-lint 全12ビュー error 0、artLint新規違反0。

### V-05 塀・道・柵の直線ラン — 中 / closed(ルール化済み 2026-08-23)

### V-06 堀縁・川岸のリム(黒帯/白茶け) — 中 / closed(ルール化済み 2026-08-23)

  岸リムが硬い菱形階段状)

    terrain-water-connected/transition、70アセット)のShoreRimがフラットな

  草側フェザー必須)/WTR-02(静水土手基部はウォーターライン必須)。リム帯は
  部分領域ゆえ全体luma平均では機械検査しにくく、L1は既存VAR-01/LUM-01の

- 検証: trench分は同一seed証跡ビュー(p04/p05/p10/p12/first)前後比較の
