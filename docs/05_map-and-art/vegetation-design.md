# 植生デザイン(松江城基準) — V-07根治の設計文書

2026-09-21のユーザー指示により確立した植生ヒエラルキーに基づく再構築計画。
既存の樹木ラスタ4種(プロジェクト初期のcodex作業由来)は**全廃**する。

## 判断基準(恒久)

1. **どんな木を**: 実在の城郭植生に従う。優先順位は
   **松江城(第一基準・固定) → 現存12天守 → 日本100名城**。
2. **どのサイズで**: Strongholdリスペクトのサイズ基準。
   成木は民家クラスの建物より明確に大きい存在感(高さ1.5〜2倍目安、
   樹冠はどっしり太く「風景の主役級」)。他アセットとの整合は前提。
3. **どんな色味で**: 既存アセットを超えない。現行樹木の実測トーン
   (不透過平均: 松(78,73,53)/杉(72,75,53)/広葉(75,76,52))の帯域に収める。

## 松江城(城山公園)の実在植生 — 調査結果(2026-09-21)

出典: 松江の花図鑑・城山公園調査(木本137種)、しまね観光ナビ、
文化遺産オンライン。

- **マツ(クロマツ・アカマツ)**: 城郭の顔。天守周り・土手の老松群。
- **クスノキ**: 大径の常緑巨樹(松江城のクスノキとして著名)。
- **ヤブツバキ 約4,200本**: 西〜北の樹林。日本三大自生椿群の一つで
  松江城の植生の最大の個性。
- スギ・ヒノキ(針葉樹林)、ケヤキ・エノキ(落葉広葉)、クリ。
- ソメイヨシノ(桜の名所)・ツツジ — 季節連動は今回スコープ外
  (通年テクスチャ方針。仕組みは畑四季と同一なので後日追加可能)。

### 下層植生(第1期追補・2026-09-27)

樹木刷新後もAIラスタの叢が混在して違和感(ユーザー指摘)のため、同方式で刷新:

| 種 | 役割 | canvas / anchor | バリアント | 造形要点 |
|---|---|---|---|---|
| 叢(bush) | 汎用低木 | 64x56 / 32,40 | 2 | リーフクランプカードの低ドーム、ロスター中間緑 |
| 草叢(weeds) | 草地の情報密度 | 64x48 / 32,32 | 2 | 乾き草色の鋭いブレード束(丸い塊は禁止=farm稲の教訓) |
| 葦(reeds) | 水際・湿地の合図 | 64x56 / 32,40 | 2 | 藁緑の稈+茶の蒲の穂、ブレードは二段テーパクアッド |

ブレードは専用 `make_blade_material`(V字ランプ+両面発光フロア0.32 —
垂直カードは光が掠るだけで黒落ちするため樹冠カードよりフロアが濃い)。
地面ブロブは台座読み(W-V07a)のため置かない。
(farm/marsh方式: 分離庫+定量ゲート+L2/Astra反復)。旧Blenderビルダーの
低ポリファセット感が既知の敗因のため、ブロブ解像度・パッド数・ノイズ変位を
引き上げ、ペインタリー後の実測(トーン帯域・分散)で反復する。

## 配置(scatterDecorations)の第1期方針

- 林分(8x8パッチ)の種バイアスを新ロスターへ再割当:
  松林(クロマツ/アカマツ)・杉林(スギ+ヒノキ調)・広葉樹林(ケヤキ+クスノキ点在)。
- **椿は城郭近傍にバイアス**(松江の「城山=椿群」を反映): 城壁・櫓の
  近傍セルでbush系の代わりにヤブツバキを優先。
- 隣接セルの同一アセット禁止(アンチクラスタ選択)を導入。
- 種分布の本格再設計(シナリオ別の植生ゾーニング)は第2期。

## 進行ゲート

1. クロマツ×3を先行制作 → 単体コンタクトシート+実マップ試し置きでL2。
   **ここで様式が立たなければ路線再考**(以降の10枚に進まない)。
   → **2026-09-27 ユーザー検収合格**(色相はラダー提示でD=粉青系を選定、
   「一番右がいい、これくらい攻めていい」)。量産GO取得。
2. 合格後、残り種を同語彙で量産 → VAR-01実効差分・artLint → 全マップ撮影
   → L2/Astra両系統 → 旧4種をmanifestから退役 → V-07クローズ。

## 確立した造形語彙(クロマツゲートで確定、全種共通)

- **テクスチャ駆動の葉**: UV付きカードにシェーダで針葉ストライプ
  (Wave BANDS+CONSTANTランプ)/広葉クランプ(Noise閾値)を描き、
  アルファ穴で「層間の空気」を作る(Stronghold技法の日本版)。
- **visible_shadow=False**(スプリグ/コア): 自己遮蔽の黒潰れ根絶。
- **Backfacing→Translucent分岐+発光フロア**: 逆光カードの黒スリバー防止。
  新種は front/translucent 両フロア0.10、コアは専用 make_core_material
  (painterly finishの影面黒落ち回避)。
- **色相D**(ユーザー選定): クロマツ sprig=(0.030,0.078,0.056)-(0.088,0.182,0.118)。
  他種はこの彩度・明度帯から種の性格分だけ振る(アカマツ黄緑寄り、
  スギ深緑、クスノキ/ケヤキ明るめ、ツバキ濃緑)。
- **露出正規化ゲート**: 種内バリアント間の不透過平均lumaΔ≤5
  (2026-09-27実測: クロマツΔ4.1、他種Δ≤3.3で合格)。
