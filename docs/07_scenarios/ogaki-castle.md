# 大垣城シナリオ(ogaki-castle)設計資料

v3の中核目標: 岐阜県大垣城の**史実上の最盛期城郭**を一つの統合マップ(128x128)として成立させる。
現存の残存城郭(復興天守+本丸周辺)ではなく、江戸初期最盛期の縄張り全体を再現対象とする。

## 1. 史実調査サマリ(2026-08-02調査)

大垣城(巨鹿城・麋城)は美濃国大垣、揖斐川水系の低湿地・輪中地帯に築かれた水城。
連郭+輪郭複合式。関ケ原の戦い(1600年)直前は石田三成ら西軍の本拠。

### 曲輪構成
- **本丸**(北): 幅約30mの水堀で完全に囲まれた「陸の孤島」。出入口は南の**鉄門**
  (二之丸と木橋で接続する唯一の連絡口)と北西の**水之手門**(水路口)のみ。
  天守+三重櫓1基(艮櫓=北東)・二重櫓3基(乾櫓=北西ほか)。
- **二之丸**(南): 本丸の南に並列(連郭式)。水堀に囲まれ、月見櫓など三重櫓4基。
  本丸への唯一の入口を扼する玄関曲輪。
- **三之丸**: 本丸・二之丸ペアを外周から包む輪郭部。**天神丸**・**竹の丸**の小曲輪を含む。
- **総構え**: 三之丸の外、武家屋敷・城下町を含め総堀で囲む。外堀と中堀の間は武家屋敷。

### 水系・堀
- 最終形は**四重の堀**(内堀/二之丸堀/中堀/総堀)。「本丸西側は三重、東側は四重」と
  方向により重数が異なる(諸説あり)。内堀幅24〜36m。
- **牛屋川(現・水門川)を外堀に転用**。北〜西を流れる。湧水豊富(自噴帯)。
- 関ケ原期(1600年)は内堀主体、総堀は慶長18年(1613年)石川忠総の増築。

### 建造物
- **天守**: 本丸北西隅、4層4階(創建時3重4階説あり)。総塗籠(白漆喰)。
- **櫓**: 最盛期で三重櫓5・二重櫓10・渡櫓26(伝)。
- **総門**: 七口之門 — 大手門(東=名古屋口)・南口・柳口・竹橋口・清水口・辰之口・小橋口。
  西総門=京口門。**美濃路**が総構え内を東西に貫通。
- 史実は平城(比高ほぼゼロ、防御は水面幅依存)。**本ゲームでは演出方針として
  本丸を高台化する**(ユーザー指定: 平山城的高低差で孤島化を強調)。

## 2. ゲームマップ設計(128x128・現行語彙トライ版)

設計原則:
1. **一本道の縦深構造**が大垣城らしさの核: 外→総門→三之丸→二之丸→木橋→鉄門→本丸。
   本丸への入口は鉄門1ヶ所のみ(第2入口を作らない)。
2. 堀リングは4重を圧縮して3重で表現: 内堀(本丸)/二之丸・三之丸堀/総堀。
   東側にのみ武家屋敷帯+中堀断片を足して非対称の「東は一枚多い」を表現。
3. 総堀の北〜西辺は幅広(4-5セル)にして水門川(川転用)を表現、他辺は幅3の掘削堀。
4. 高低差: 本丸をelevation 2の高台(崖+スロープなし=橋・門経由のみ)、
   二之丸をelevation 1、他は平地。史実(平城)とは異なる演出上の選択。
5. 美濃路: 東総門(名古屋口)⇔西総門(京口)を結ぶ東西貫通道。堀端で屈曲させる。

### ユニット・ゲームプレイ
- プレイヤー守備隊: 本丸・二之丸・三之丸に分散配置(concentric-castle準拠の規模)。
- 敵: マップ外縁(東側街道方面)に攻城方。既存シナリオのAIプロファイル流用。
